# Privacy Policy

_Last updated: 2026-10-27_

InventoryWizard does not collect personal information. This page explains the little data that does leave your computer or server, where it goes, and how to turn it off.

## Paper/Spigot plugin: bStats

The Paper/Spigot plugin uses [bStats](https://bstats.org) to collect anonymous usage statistics. These help me see which Minecraft versions, server software and Java versions to keep supporting. The results are public at [bstats.org/plugin/bukkit/InventoryWizard/34984](https://bstats.org/plugin/bukkit/InventoryWizard/34984).

### What is sent

About every 30 minutes, the server sends bStats:

- **A random server ID**, generated by bStats the first time it runs. It identifies the server installation only, not any player.
- **Server information:** number of players online, online mode, Minecraft version, server software (for example Paper or Spigot), and InventoryWizard's version
- **System information:** Java version, operating system name, version and architecture, and the number of CPU cores
- **Country**, which bStats works out from the server's IP address. The IP address is not stored.

InventoryWizard adds no custom charts. It sends nothing beyond what every bStats-enabled plugin sends by default.

### What is not sent

No player names, UUIDs, IP addresses, chat messages, inventory contents or world data are sent to bStats or anywhere else.

### Opting out

bStats is on by default. To turn it off, open `plugins/bStats/config.yml` and set:

```yaml
enabled: false
```

Then restart the server. This turns bStats off for every plugin on the server that uses it.

### bStats' own policy

bStats is run independently of InventoryWizard. How it stores and handles the data is covered by its own [privacy policy](https://bstats.org/privacy-policy).

## Client mod: update check

The client mod (Fabric, Quilt, NeoForge and Forge) collects no statistics. When the game starts, it asks the [Modrinth API](https://modrinth.com) whether a newer version of InventoryWizard exists. The request includes your Minecraft version, your mod loader and InventoryWizard's version. Like any web request, it also reveals your IP address to Modrinth, under [Modrinth's privacy policy](https://modrinth.com/legal/privacy).

To turn it off, disable **Check for Updates** in the InventoryWizard settings screen.

## Data stored locally

The Paper plugin saves each player's sorting mode and locked slots, keyed by their Minecraft UUID, in a database inside the server's `plugins/InventoryWizard` folder. The client mod saves your settings in your `.minecraft/config` folder. This data stays on the server or computer and is never sent anywhere.
